# Module Assignment Semantic Colours

**Date:** 2026-08-16

Use planner-native semantic colour to make assignment provenance scannable without replacing explicit text labels.

- Manually assigned uses cyan.
- Randomly assigned uses green.
- Required dependency uses amber.
- Not assigned uses neutral grey.
- Conflict and incompatibility reserve red.

Catalogue cards carry a four-pixel provenance rail and subtle matching tint. Status badges use the same mapping. Assignment Summary and plan-wide usage rows include a matching marker plus the full text label. The selected module retains a separate cyan outer focus treatment so selection is not confused with provenance. All states remain understandable without colour.
