Network Topology Layout Style

What kind of "traditional network diagram" layout are you thinking?

Tiered / Layered

Classic network diagram with horizontal tiers (WAN → Core → Targets). Nodes arranged in rows by role. Clean top-to-bottom flow. Think Cisco/Visio style.

Star / Hub-and-Spoke

Central event/router node with VMs radiating outward in a circle. Simple and compact. Good for showing one team's setup at a glance.

Rack / List View

Less of a graph, more of a structured rack diagram. Shows one representative team setup as a vertical stack with a shared backbone. Compact, information-dense.
