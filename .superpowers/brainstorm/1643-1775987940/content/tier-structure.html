What goes in each tier?

Since teams are removed, how should VMs be organized into tiers?

Tiers by VM role

Each tier = a VM role: Event → Target VMs → App VMs → Attacker. Roles come from the vm_quota JSON ("role": "target" vs "attacker"). Clean separation by function.

Grouped by vm_quota type

VMs grouped by their quota key (e.g. "ubuntu_target ×3", "red_team ×1"). Groups can expand to show individual VMs. Shows the template structure clearly.
