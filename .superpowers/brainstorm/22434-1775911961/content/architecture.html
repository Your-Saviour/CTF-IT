How the topology page is structured

API Endpoint: GET /api/topology-data

Response shape
{ "nodes": [ {"id": "event-1", "type": "event", "label": "Spring CTF", "status": "open"}, {"id": "team-3", "type": "team", "label": "Alpha", "event_id": "event-1", "color": "#ffb400"}, {"id": "vm-7", "type": "vm", "label": "vm-alpha-01", "hostname": "vm-alpha-01", "ip": "45.76.12.34", "status": "active", "os": "Ubuntu 22.04", "team_id": "team-3", "event_id": "event-1", "modules_total": 8, "modules_completed": 5} ], "links": [ {"source": "event-1", "target": "team-3"}, {"source": "team-3", "target": "vm-7"} ] }

D3 Force Configuration

Force simulation setup
const simulation = d3.forceSimulation(nodes) .force("link", d3.forceLink(links).id(d => d.id) .distance(d => { if (d.source.type === "event") return 180; // event→team return 100; // team→vm })) .force("charge", d3.forceManyBody().strength(-300)) .force("center", d3.forceCenter(width/2, height/2)) .force("collision", d3.forceCollide() .radius(d => nodeRadius(d) + 10));

Node Rendering

  • Event nodes: Large circle (r=50), cyan border, glow effect, event name label
  • Team nodes: Medium circle (r=35), unique color per team, team name label
  • VM nodes: Small circle (r=22), border color = status, hostname label, hover shows IP + progress
  • Links: Dashed lines, colored to match target team, opacity 0.3

Interactions

  • Drag: Any node can be dragged, simulation re-heats on drag
  • Zoom/Pan: d3.zoom() on SVG, scroll to zoom, drag background to pan
  • Hover: Tooltip with details (IP, OS, module progress bar for VMs)
  • Right-click VM: Context menu with: View Details, Re-provision, Assign Modules, Export Playbook, Destroy
  • Right-click Team: Context menu with: View Team, Add VM, Delete Team
  • Double-click: Navigate to detail page

Live Polling

  • Fetch /api/topology-data?event_id=X every 5 seconds
  • Diff against current graph — add/remove nodes, update status colors
  • Smooth transitions on status change (color fade, not instant swap)
  • New nodes animate in from center, removed nodes fade out
  • Pulse animation on nodes that just changed status
