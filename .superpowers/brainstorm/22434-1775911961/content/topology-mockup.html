Design Summary

  • Hierarchy: Event (center) → Teams (mid-ring, colored) → VMs (outer, status-colored)
  • Force layout: Teams cluster around their event, VMs cluster around their team
  • Status: VM border color = status (green/amber/red/grey)
  • Context menu: Right-click any node for quick actions
  • Live polling: Every 5s, fetches VM status and updates node colors/positions
  • Event filter: Dropdown to scope to a single event or show all
  • Zoom/pan: D3 zoom behavior on the SVG canvas
